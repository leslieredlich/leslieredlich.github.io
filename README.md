# leslieredlich.github.io

Portafolio personal de Leslie Redlich — Desarrolladora Full Stack.

**En línea:** https://leslieredlich.github.io

## Cómo está hecho

HTML, CSS y JavaScript sin dependencias ni proceso de build. Se publica solo con
hacer push a `main`.

```
index.html
assets/
  css/styles.css
  js/main.js
  img/            capturas de los proyectos
```

## Editar

Cualquier cambio en `index.html` se refleja en el sitio uno o dos minutos después
del push. Para ver el resultado antes de publicar, basta abrir `index.html` en el
navegador.
